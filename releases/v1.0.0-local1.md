# v1.0.0-local1

First packaged release of the local ELAN TOD integration for USB fingerprint reader `04f3:0c4b`.

## Verified platform

- Lenovo ThinkBook 14 G2 ARE
- Ubuntu 26.04 Resolute
- Kernel `7.0.0-31-generic`
- `fprintd 1.94.5-4`
- `libfprint-2-tod1 1:1.95.1+tod1-0ubuntu2`

## Included package

`elan-fingerprint-04f3-0c4b-local_1.0.0+local1_amd64.deb`

SHA256:

```text
9893258dfeb04259312fccb465ac372440e2e972787966794e63b87c9c520b44
```

Verify after download:

```bash
sha256sum elan-fingerprint-04f3-0c4b-local_1.0.0+local1_amd64.deb
```

## What this package installs

- proprietary ELAN TOD driver under `/opt/elan-fingerprint/driver/`
- private `libcrypto.so.1.1` under `/opt/elan-fingerprint/lib/`
- TOD symlink under `/usr/lib/x86_64-linux-gnu/libfprint-2/tod-1/`
- udev selection rule for USB ID `04f3:0c4b`
- package documentation and internal checksums

The package intentionally does **not** modify PAM.

## Verified functionality

- fingerprint enrollment
- repeated `fprintd-verify` matches
- sudo authentication via fingerprint
- sudo password fallback
- GNOME lock-screen authentication
- graphical logout/login authentication

## Important removal order

If fingerprint authentication was enabled through PAM, disable it first with:

```bash
sudo pam-auth-update
```

Then verify password authentication works before removing the driver package:

```bash
sudo -k
sudo -v
```

Only after password authentication is confirmed:

```bash
sudo apt purge elan-fingerprint-04f3-0c4b-local
```

See `docs/UNINSTALL.md` for the full safe removal procedure.

## Known limitation

The TOD driver does not provide the same fingerprint LED behaviour as the Windows driver. LED control is intentionally outside this package.
