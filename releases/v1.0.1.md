Documentation-only maintenance release for the ELAN `04f3:0c4b` fingerprint integration.

This release does **not** introduce a new driver build or a new Debian package version. The packaged binary remains:

`elan-fingerprint-04f3-0c4b-local_1.0.0+local1_amd64.deb`

