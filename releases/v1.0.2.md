# v1.0.2

[English](v1.0.2.md) | [Русский](v1.0.2.ru.md)

Packaging, licensing, documentation, and repository-maintenance release for the ELAN `04f3:0c4b` fingerprint integration.

This is the first release using the normalized Debian package name and version:

`elan-fingerprint-04f3-0c4b_1.0.2_amd64.deb`

SHA256:

```text
daad05b78e87f3e5c8ec4dfc77180933376135831c96588d6767406cfff78c72
```

## What changed since v1.0.1

### Package naming and version normalization

The package no longer uses `local` in its current name or version:

- package name: `elan-fingerprint-04f3-0c4b`
- Debian version: `1.0.2`
- package file: `elan-fingerprint-04f3-0c4b_1.0.2_amd64.deb`

The previously published package was named `elan-fingerprint-04f3-0c4b-local` with Debian version `1.0.0+local1`. Version `1.0.2` contains `Replaces` and `Conflicts` metadata for that legacy package name so the new package can take over the same installed paths.

The proprietary ELAN TOD driver and bundled `libcrypto.so.1.1` payloads were not replaced during this rebuild. Their SHA256 values remain:

```text
be47d4e63bdb541397d1a0d853115d034c36179580aade16e3b52bdcd1dbc3f0  /opt/elan-fingerprint/driver/libfprint-2-tod1-elan.so
bf99926de2ce739d3fdccc4a551d97d64aac6e968589aaad9dc4ac8d143b519a  /opt/elan-fingerprint/lib/libcrypto.so.1.1
```

The package-level OpenSSL documentation is now installed under `/usr/share/doc/elan-fingerprint-04f3-0c4b/` rather than the legacy `...-local/` path.

### OpenSSL 1.1 provenance and licensing

The provenance and redistribution terms for the bundled `libcrypto.so.1.1` compatibility library are documented explicitly.

- source binary package: `libssl1.1_1.1.1f-1ubuntu2.24_amd64.deb`
- corresponding Ubuntu source package: `openssl 1.1.1f-1ubuntu2.24`
- verified package, library, and source-file SHA256 values are recorded in the repository
- OpenSSL 1.1.1f is documented as being distributed under both the **OpenSSL License and Original SSLeay License**
- the complete upstream OpenSSL 1.1.1f license text and a provenance record are included in the package
- OpenSSL remains third-party software and is not relicensed under the repository's Apache-2.0 license

See [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md) and [`docs/en/PACKAGE.md`](../docs/en/PACKAGE.md).

## Package validation

The rebuilt package was checked for:

- `Package: elan-fingerprint-04f3-0c4b`
- `Version: 1.0.2`
- `Architecture: amd64`
- migration metadata for `elan-fingerprint-04f3-0c4b-local`
- unchanged SHA256 values for the ELAN TOD and `libcrypto.so.1.1` payloads
- ELAN driver `RUNPATH=/opt/elan-fingerprint/lib`
- `libcrypto.so.1.1` recorded as a required ELF dependency
- TOD symlink target `/opt/elan-fingerprint/driver/libfprint-2-tod1-elan.so`
- package-local OpenSSL license and provenance files under the normalized `/usr/share/doc/elan-fingerprint-04f3-0c4b/` path

This rebuild changes package metadata and documentation but does not change the ELAN driver or OpenSSL binary payloads.

## Third-party components

The OpenSSL 1.1 compatibility component has documented provenance, source-package mapping, checksums, and license notices.

The proprietary ELAN TOD binary is unchanged. Its redistribution status remains unresolved and continues to be tracked in Issue #1. This release must not be interpreted as resolving or granting redistribution rights for that component.
