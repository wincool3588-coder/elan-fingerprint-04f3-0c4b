# v1.0.2

[English](v1.0.2.md) | [Русский](v1.0.2.ru.md)

Релиз с обновлением документации, лицензионных сведений и материалов сопровождения проекта для поддержки сканера отпечатков ELAN `04f3:0c4b`.

Этот релиз **не содержит новой сборки драйвера ELAN и не изменяет версию Debian-пакета**. Проверенный бинарный пакет остаётся прежним:

`elan-fingerprint-04f3-0c4b-local_1.0.0+local1_amd64.deb`

SHA256:

```text
9893258dfeb04259312fccb465ac372440e2e972787966794e63b87c9c520b44
```

## Что изменилось после v1.0.1

### Происхождение и лицензирование OpenSSL 1.1

Теперь явно документированы происхождение и условия распространения приватной библиотеки совместимости `libcrypto.so.1.1`.

- исходный бинарный пакет: `libssl1.1_1.1.1f-1ubuntu2.24_amd64.deb`
- соответствующий пакет с исходным кодом Ubuntu: `openssl 1.1.1f-1ubuntu2.24`
- в репозитории зафиксированы проверенные SHA256 пакета, библиотеки и файлов исходного пакета
- указано, что OpenSSL 1.1.1f распространяется одновременно по **OpenSSL License и Original SSLeay License**
- полный исходный текст лицензии OpenSSL 1.1.1f и сведения о происхождении включены в дерево пакета
- OpenSSL остаётся сторонним программным обеспечением и не перелицензируется под Apache 2.0 этого репозитория

См. [`THIRD_PARTY_NOTICES.ru.md`](../THIRD_PARTY_NOTICES.ru.md) и [`docs/ru/PACKAGE.md`](../docs/ru/PACKAGE.md).

### Синхронизация документации

- синхронизированы сведения о лицензировании в английской и русской документации
- обновлён `README.md`, где теперь явно указан лицензионный статус `libcrypto.so.1.1`
- улучшена русская терминология и удалены лишние англицизмы при сохранении точных технических обозначений
- уточнены русские документы по диагностике, удалению, безопасности и участию в проекте

### Сопровождение репозитория и правила участия

В репозиторий добавлены дополнительные материалы сопровождения:

- шаблоны задач для сообщений об ошибках, отчётов о совместимости и запросов новых возможностей
- шаблон Pull Request
- правила участия в проекте на английском и русском языках
- политика безопасности на английском и русском языках
- Кодекс поведения на английском и русском языках

Эти материалы фиксируют правила участия, сообщения об уязвимостях, требования к переводу документации и порядок работы со сторонними бинарными компонентами.

## Состояние пакета

В `v1.0.2` **нет изменений бинарных файлов, драйвера, поведения во время работы, PAM, udev или версии Debian-пакета**.

Версия Debian-пакета остаётся `1.0.0+local1`, а указанная выше контрольная сумма SHA256 остаётся действительной для опубликованного бинарного файла. В текущем дереве пакета появились дополнительные лицензионные файлы OpenSSL, поэтому любая будущая пересборка из этого дерева создаст `.deb` с другой контрольной суммой; такой бинарный файл необходимо учитывать как отдельный артефакт.

## Сторонние компоненты

Для библиотеки совместимости OpenSSL 1.1 теперь документированы происхождение, соответствующий пакет с исходным кодом, контрольные суммы и лицензионные уведомления.

Проприетарный бинарный модуль ELAN TOD не изменялся. Его статус распространения остаётся неурегулированным и продолжает отслеживаться в Issue #1. Этот релиз не следует трактовать как решение вопроса о правах на распространение этого компонента или как предоставление таких прав.
