# Политика безопасности

[English](SECURITY.md)

## Поддерживаемые версии

Проект небольшой и в настоящий момент поддерживает только последнее опубликованное состояние репозитория и последний документированный выпуск пакета, если в отдельном уведомлении по безопасности не указано иное.

| Версия | Поддержка |
| --- | --- |
| Последний релиз | Да |
| Старые релизы | По возможности |
| Неопубликованные или локально изменённые сборки | Без гарантий |

Поддержка безопасности здесь относится к созданным в проекте packaging-материалам, скриптам, документации и интеграционной логике. Проприетарные компоненты ELAN и другие сторонние бинарные файлы остаются под ответственностью их поставщиков и регулируются их собственными условиями.

## Сообщение об уязвимости

**Не создавайте публичный Issue**, если уязвимость может подвергнуть пользователей риску.

Предпочтительный путь: используйте private vulnerability reporting GitHub для этого репозитория через раздел **Security**, если эта возможность доступна.

Если private vulnerability reporting недоступен, сначала свяжитесь с сопровождающим через GitHub, не публикуя детали эксплуатации, учётные данные, персональные данные или другую чувствительную информацию. Сначала согласуйте приватный канал раскрытия, и только затем передавайте чувствительные технические детали.

По возможности укажите:

- затронутый релиз или commit
- версии Ubuntu и ядра
- модель устройства и USB ID
- версию пакета
- краткое описание влияния
- шаги воспроизведения или proof of concept
- затрагивает ли проблема аутентификацию, границы привилегий, установку пакета, права файлов, загрузку библиотек, обновление или удаление
- известный способ смягчения риска, если он есть

## Чего ожидать

Корректный отчёт будет проверен на применимость и воспроизводимость. Сопровождающий может запросить дополнительную диагностику. Публичное раскрытие желательно отложить до появления исправления или разумного способа снижения риска, если немедленное раскрытие не требуется для защиты пользователей.

## Границы ответственности

Это неофициальный интеграционный проект, не связанный с Ubuntu, Lenovo, ELAN или OpenSSL. Уязвимости, находящиеся исключительно в upstream- или проприетарном стороннем компоненте, возможно, потребуется также сообщить соответствующему поставщику.

Вопросы лицензирования и распространения, не являющиеся уязвимостями безопасности, следует оформлять обычным Issue с меткой `legal/licensing`, а не через security-канал.
