# Code of Conduct

[Русская версия](CODE_OF_CONDUCT.ru.md)

## Our standard

Participation in this project should be professional, respectful, and focused on improving the software and documentation.

Examples of expected behavior include:

- giving technically useful, good-faith feedback
- disagreeing with ideas without attacking people
- respecting different levels of experience
- keeping bug reports, reviews, and discussions relevant to the project
- handling security and privacy-sensitive information responsibly

Unacceptable behavior includes harassment, threats, discriminatory or demeaning language, deliberate disruption, publishing another person's private information, or repeatedly ignoring project moderation decisions.

## Scope

This code applies to repository issues, pull requests, reviews, discussions, and other project spaces where a participant is representing this project.

## Enforcement

The repository maintainer may edit, hide, lock, or remove content and may restrict participation when behavior violates this code.

When reporting conduct problems, avoid posting private or sensitive personal information publicly. Contact the maintainer through GitHub and provide only the information needed to review the incident.

## Enforcement principles

Moderation should be proportionate to the behavior and its impact. Minor problems should normally receive a request to correct the behavior; repeated or serious violations may result in stronger restrictions.

This project-specific code of conduct is intentionally concise. It is an explicitly documented alternative to adopting a larger external code-of-conduct framework.
